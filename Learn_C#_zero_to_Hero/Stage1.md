# Stage 1: Learn C# Properly
Before learning frameworks, learn the language.

Focus on:
- Variables, data types, operators, and control flow
- Methods, classes, records, structs, and enums
- Value types and reference types
- Exception handling
- Collections
- Generics
- Delegates and events
- LINQ
- Pattern matching
- Nullable reference types
- Asynchronous programming with async and await

Do not rush through C# simply because ASP.NET Core looks more exciting.
Framework knowledge changes. Language fundamentals remain valuable for much longer.
You should understand not only how to write working C# code, but also what happens when that code runs.

For example:
When should you use a class instead of a record?
What is the difference between IEnumerable<T> and IQueryable<T>?
Why can blocking asynchronous code cause problems?
When does an object get allocated on the heap?
What is the purpose of nullable reference types?
You do not need to master every advanced detail immediately. However, you should develop enough understanding to write readable and predictable programs.
